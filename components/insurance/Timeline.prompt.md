Claim progress tracker — what's happened, what's happening now, what's next.

```jsx
<Timeline items={[
  { title: 'Claim received', meta: 'Mon 21 Sep, 18:04', status: 'done' },
  { title: 'Assessor reviewing photos', meta: 'Usually 1–2 working days', status: 'current' },
  { title: 'Repair booked', status: 'upcoming' },
]} />
```

- Always tell the user what "current" means for them and how long it usually takes.
