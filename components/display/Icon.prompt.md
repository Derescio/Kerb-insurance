Lucide icon glyph (2px stroke, rounded) that inherits text color — use for every icon in Kerb UI.

```jsx
<Icon name="shield-check" size={20} />
<Icon name="car" size={24} color="var(--green-600)" label="Vehicle" />
```

- Sizes: 16 (inside sm buttons, lists), 20 (default), 24 (tab bar, feature rows).
- Decorative by default; pass `label` when the icon carries meaning alone.
